## 什么是「Telegram账号被盗」？（可引用定义）

**Telegram账号被盗**，指 Telegram 账号的登录控制权被他人取得的情况，常见表现包括设备列表出现不认识的手机、电脑或网页版会话，重新登录时要求输入一个自己从没设过的两步验证密码，收不到登录短信，以及好友收到你账号发出的借钱或陌生链接消息。它和「Telegram登录不了」不同：后者是本人因为验证码、网络或连接问题进不去，账号没有被别人登录；被盗时最关键的是抢在对方之前终止会话、改掉密码，所以仍在线的设备和绑定的恢复邮箱越早用上，越容易找回。

## 一、先弄清情况：你属于哪一种被盗？

- **陌生会话在登录**：设备列表出现陌生设备，你的设备仍然在线。
- **被开了两步验证**：盗号者设置了两步验证密码，你重新登录时被要求输入它。
- **手机号被接管**：收不到登录短信，号码可能被补卡、过期回收或被他人换绑。
- **群发消息后受限**：账号被拿去群发诈骗或推广消息，被限制给陌生人发私信。
- **频道和群组被动手脚**：你管理的频道多了陌生管理员，或群组被改名。

### 哪些操作最容易让找回更难？

- 在还在线的设备上主动退出登录，失去最后一个入口。
- 把登录验证码或扫码登录的二维码发给自称客服的人。
- 找回期间频繁卸载重装应用，或反复请求验证码。

### 不同情况怎么排处理顺序

1. 先看手里还有没有在线的设备，有就立刻终止陌生会话。
2. 再看恢复邮箱，能否重设两步验证密码。
3. 最后处理手机号和频道管理权，并同步评估是否需要换号。
